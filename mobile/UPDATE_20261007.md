# Finance update, 7 October 2026

This Expo client is the source for the finance web application and the Android/iOS
app. Build the web release with `npm run build:web` from `mobile/`, not Vite's old
`frontend/` application.

- Appearance now includes **Đen trắng**, saved on the device. It uses a warm white
  background, charcoal controls, neutral chart colors and the generated wallet
  logo. Selecting it preserves the previous accent preference.
- **Hồ sơ → Quản lý thu chi → Chỉ quản lý khoản chi** defaults to enabled and is
  saved per account. It hides new income actions. Existing income records remain
  visible and editable.
- Native bottom navigation replaces the central plus icon with **Quét QR thanh
  toán**. The web keeps its existing add action. Camera permission is requested
  only on explicit use; camera previews stop when backgrounded. QR images are
  decoded on-device. Only VND VietQR account transfers with a valid CRC are
  supported. The user selects their installed banking app; bank opening/autofill
  depend on that app. Transfer details go to VietQR.io when opening its deep link.
  Saving an expense requires explicit user confirmation, with an idempotent
  request ID. It is not bank-verified payment status.
- Native credentials remain in Expo SecureStore (iOS Keychain / Android Keystore).
  No password is cached. A rotating refresh token renews the access token after
  its one-day expiry. The server stores only hashes, permits a 30-second retry of
  one rotation, and rejects revoked, inactive or session-version-invalidated
  accounts. The refresh session expires after **180 days of inactivity**, extended
  on use. A network failure preserves the saved session for retry. Signing out
  removes local credentials even offline; online logout also revokes the session.
  Valid older native sessions are upgraded without requiring login.
- Migration 030 repairs the notification trigger and historical amounts captured
  in notification messages. VND renders as `85.000 ₫`; two-decimal currencies keep
  cents. Migrations 031 and 032 add native sessions and expense-only preferences.

Checks: `npm run test`, `npm run typecheck`, `npm run lint`, `npm run build:web`,
`npm run export:native`. Backend integration checks require the three migrations
and `RUN_DB_TESTS=1 node --test test/nativeSessions.integration.test.js`.

Native camera and session changes require a new signed mobile build (version
1.0.2, Android versionCode 6). Publishing web assets cannot update installed apps.
Test camera permission denial, real VietQR/bank links, app restart, token renewal,
and offline retry on Android/iPhone before store release.
